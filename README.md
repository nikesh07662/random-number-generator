# 🎲 Random Number Generator

A clean, modern, and interactive web application designed to generate random numbers, roll dice, flip coins, and pick random winners. Built with a sleek dark design, smooth animations, and fun sound effects.

---

## 💡 What is This App?

Have you ever needed a quick way to:
- Pick a lucky lottery number?
- Roll a die or flip a coin when you don't have one nearby?
- Draw a random winner from a list of contestants or team members?
- Settle a friendly decision or generate numbers for statistics and school projects?

**Random Number Generator** makes all of this simple, fair, and fun. It runs entirely in your web browser with zero setup required for the user.

---

## ✨ Features Made Simple

- 🔢 **Pick Any Range**: Choose any starting number (minimum) and ending number (maximum). It even works with **negative numbers** (like `-50` to `50`).
- 🔘 **One-Click Generation**: Press the **Generate** button or tap the **Spacebar** on your keyboard to instantly see your result with a rolling slot-machine animation.
- 🎯 **Decimals Supported**: Need fractional numbers (like `1.5` or `0.05`)? Turn on decimal mode and choose how many decimal places you want.
- 🎲 **Dice Roller**: Roll standard tabletop dice (6-sided, 20-sided for games like Dungeons & Dragons, and more). It even celebrates with confetti if you roll a Natural 20!
- 🪙 **Coin Flipper**: Flip a 3D coin and keep track of how many times it lands on Heads vs. Tails.
- 🏆 **Raffle & List Picker**: Type in names or items, and let the app randomly pick one or more winners with confetti explosions.
- 📊 **Live Distribution Chart**: A simple, colorful chart that shows you how frequently different numbers appear over time.
- 🕒 **History Log**: Keeps a record of your recent rolls so you never lose track. You can copy results to your clipboard or download them as an Excel-friendly CSV spreadsheet.
- 🔊 **Satisfying Sounds**: Subtle mechanical clicks, chimes, and coin flips make each roll feel tactile (with an easy mute toggle if you prefer silence).

## 🚀 How to Run the Project

You can run this project on your computer in 3 easy steps:

### 1. Requirements
Make sure you have **Node.js** installed on your computer (free from [nodejs.org](https://nodejs.org/)).

### 2. Install
Open your terminal (or Command Prompt) inside this project folder and type:
```bash
npm install
```

### 3. Start
Start the application by running:
```bash
npm run dev
```
Then click the link shown on your screen (usually `http://localhost:5173`) to open the app in your browser!

- **React**: For creating smooth and responsive user interface components.
